# Что умеет

· Генерирует пароли от 4 до 100 символов
· Делает PIN-коды, Passphrase и API-токены
· Проверяет надежность и делает SHA-256 хэш
· Сохраняет пароли в файл и копирует в буфер
· Показывает честный онлайн и время работы

# Генератор паролей для Termux

Терминальный скрипт для генерации паролей, токенов и проверки надежности.

## установка 
`git clone https://github.com/Talolpa/Loliikgen.git`
`cd Loliikgen`
## активация:
python Loliik.py
